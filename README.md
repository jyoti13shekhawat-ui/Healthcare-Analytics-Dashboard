# Healthcare-Analytics-Dashboard
An interactive healthcare analytics dashboard built using Power BI.

## Project Overview
This project is an interactive healthcare analytics dashboard built using Power BI to analyze patient admissions, doctor performance, disease trends, and hospital insights.

## Objectives
- Monitor hospital performance
- Analyze patient demographics
- Track doctor workload
- Identify common diseases
- Generate healthcare insights

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV Dataset

## Dashboard Pages
1. Overview Dashboard
2. Patients Dashboard
3. Doctors Dashboard
4. Disease Dashboard
5. Insights Dashboard

## KPIs
- Total Patients
- Insurance Coverage Cost
- Average Wait Time
- Satisfaction Score
- Average Billing Cost
- Peak Visit Hour

## Features
- Interactive slicers
- Heatmaps
- Trend analysis
- KPI cards
- Drill-down insights

## Key Insights
- Peak hospital traffic occurs during early morning hours in May.
- Senior patients have longer stays.
- Diabetes & Obesity generate the highest billing.
- Hypertension is the most common disease.
